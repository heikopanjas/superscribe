Scalar.mlmodel is a repository-owned, specification-version-1 Core ML GLM
regressor with one double input `x`, one double output `y`, weight 1 and offset 0.
It contains no trained weights or external assets. TestHelpers compiles it into
a temporary directory to construct storage-only FluidAudio model stubs.

Schema: https://github.com/apple/coremltools/tree/main/mlmodel/format
